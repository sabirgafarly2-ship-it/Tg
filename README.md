# Percent Goal Mobile App

Простое мобильное приложение на React Native (Expo), которое показывает процент выполнения цели.

## Функции
- Ввод установленного значения (цели).
- Ввод текущего значения.
- Автоматический расчет процента выполнения.
- Визуальный прогресс-бар.

## Запуск
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите приложение:
   ```bash
   npm run start
   ```
3. Откройте на телефоне через Expo Go или эмулятор.

## Формула
`(текущее значение / цель) * 100`
